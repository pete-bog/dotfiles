Plugins vendored from [oh-my-zsh](https://github.com/ohmyzsh/ohmyzsh) (MIT, see
`LICENSE.txt`), loaded by `~/.zshrc` without oh-my-zsh itself. Run
`../update-plugins.sh` to refresh them from upstream.

| Here                  | Upstream               |
| --------------------- | ---------------------- |
| `git-lib/`            | `lib/git.zsh`          |
| `git/`                | `plugins/git`          |
| `virtualenv/`         | `plugins/virtualenv`   |
| `macos/` (Darwin only)| trimmed `plugins/macos`, edited by hand |

`colors/` and `windowtitle/` are not from upstream.
